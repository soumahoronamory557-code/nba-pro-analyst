# NBA PRO ANALYST

Application web bilingue français/anglais, entièrement gratuite.

## Fonctions
- Résultats NBA avec actualisation automatique toutes les 60 secondes
- Classement des conférences
- Comparaison statistique de joueurs (saisie manuelle)
- Projection indicative des points
- Interface adaptée aux téléphones et structure PWA

## Lancer en local
Prérequis : Node.js 18 ou plus.

```bash
npm install
npm start
```
Puis ouvrir http://localhost:3000

## Déploiement Render
Le fichier `render.yaml` configure un service web Node gratuit pour les tests.
1. Importer ce dépôt GitHub dans Render.
2. Laisser les commandes `npm install` et `npm start`.
3. Déployer et ouvrir l'adresse fournie.

## Données
Les résultats et classements utilisent des points d'accès ESPN non officiels et non garantis. Ils peuvent changer ou être indisponibles. Les comparaisons utilisent des statistiques saisies manuellement. Les projections ne sont pas des conseils de pari.
